# Kees Hessels Engineering Portfolio

Static portfolio website for Kees Hessels, focused on software architecture, electronics, embedded systems, industrial IoT and technical leadership.

## Files

- `index.html` - homepage with hero, services, projects, experience, skills, article previews and contact CTA.
- `about.html` - professional story and engineering principles.
- `resume.html` - online CV with printable layout.
- `articles.html` - article landing page.
- `contact.html` - contact options.
- `styles.css` - custom responsive visual system.
- `script.js` - mobile navigation and print action.
- `favicon.svg`, `site.webmanifest`, `robots.txt`, `sitemap.xml` - deployment and SEO basics.

## Deployment

Upload the files to any static web server. No backend, database, build step, Node.js, PHP or framework runtime is required.

## Assets

The homepage uses the supplied portrait assets and preserves the PDF resumes for download.
